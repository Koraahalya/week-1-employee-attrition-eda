# Week 5 Internship Task
## Comprehensive Data Science Project Reporting and Strategic Recommendations

### Project
Employee Attrition Analysis, Statistical Validation, and Machine Learning Prediction

### Dataset
IBM HR Analytics Employee Attrition & Performance

### Domain
Human Resources / Employee Retention

### Objective
The objective of Week 5 was to integrate the data science techniques developed during the previous internship weeks into a comprehensive end-to-end project. The project combines data analysis, visualization, statistical hypothesis testing, machine learning, model evaluation, risk analysis, and strategic recommendations.

### Project Workflow
- Data acquisition and cleaning
- Exploratory data analysis
- Advanced data visualization and storytelling
- Statistical hypothesis testing
- Machine learning model development
- Model evaluation
- Feature analysis
- Employee attrition risk analysis
- Strategic recommendations

### Statistical Analysis
A Chi-Square Test of Independence was used to examine the association between overtime status and employee attrition.

- Chi-Square Statistic: 87.5643
- Degrees of Freedom: 1
- P-value: p < 0.001
- Cramér's V: 0.2441
- Decision: Reject the Null Hypothesis

### Machine Learning Model
Logistic Regression was used to predict employee attrition.

### Model Results
- Accuracy: 86.05%
- Precision: 61.54%
- Recall: 34.04%
- F1-Score: 43.84%
- AUC: 0.8079

### Key Finding
The analysis identified a statistically significant association between overtime and employee attrition. The machine learning model achieved useful predictive performance, but its low recall for the Attrition class shows that further improvement is required before operational use.

### Strategic Focus
The project recommends monitoring overtime exposure, investigating employee satisfaction and high-attrition job roles, improving the predictive model, and using model predictions as decision-support information rather than as automatic employment decisions.

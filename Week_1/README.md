# Week 1 Internship Task
## Data Acquisition, Cleaning, and Exploratory Data Analysis

### Dataset
IBM HR Analytics Employee Attrition & Performance

### Domain
Human Resources / Employee Attrition

### Objective
The objective of this task is to perform the basic data preparation and exploratory analysis required for a data science project. The dataset was acquired, inspected, cleaned, and analyzed using Python.

### Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Work Completed
The Week 1 task includes:

1. Data acquisition and initial inspection.
2. Identification and handling of missing values.
3. Duplicate checking and data cleaning.
4. Data type verification.
5. Preparation of the cleaned dataset.
6. Exploratory data analysis using statistical summaries.
7. Creation of visualizations to understand employee attrition patterns.
8. Analysis of relationships between attrition and selected employee-related variables.

### Key Insights
The exploratory analysis shows that employee attrition is not evenly distributed across the dataset. Differences can be observed across departments, overtime status, monthly income, job satisfaction, and work-life balance. The correlation analysis also helps identify relationships among numerical employee attributes. These findings provide a foundation for deeper analysis of employee retention and possible factors associated with attrition.
